# Directorio de sonidos

Coloca aquí el archivo de sonido `flip.mp3` para los efectos de audio al pasar páginas.

## ¿Dónde conseguir sonidos?

Puedes descargar sonidos de página gratis en:

1. **Freesound.org**
   - https://freesound.org
   - Busca: "page turn" o "paper flip"
   - Descarga en formato MP3

2. **Zapsplat.com**
   - https://www.zapsplat.com
   - Categoría: Paper & Cardboard
   - Formato: MP3

3. **Pixabay**
   - https://pixabay.com/sound-effects/
   - Busca: "page turning"

## Requisitos del archivo

- **Nombre:** `flip.mp3`
- **Formato:** MP3
- **Duración:** 0.5 - 1 segundo
- **Tamaño:** < 100KB

## Ejemplo de estructura

```
public/
└── sounds/
    └── flip.mp3    ← Coloca tu archivo aquí
```
