# 🎵 INSTRUCCIÓN IMPORTANTE: Agregar archivo de sonido

## ⚠️ ACCIÓN REQUERIDA

Para activar el efecto de sonido al voltear páginas, debes descargar un archivo de sonido MP3.

### Pasos Rápidos:

1. **Visita uno de estos sitios:**
   - https://freesound.org/search/?q=page+flip
   - https://pixabay.com/sound-effects/search/page/
   - https://mixkit.co/free-sound-effects/page/

2. **Descarga un sonido de "page flip" o "book page"**
   - Duración: 0.5-1 segundo
   - Formato: MP3
   - Tamaño: < 200KB

3. **Guárdalo con el nombre exacto: `flip.mp3`**

4. **Colócalo en la carpeta:**
   ```
   public/sounds/flip.mp3
   ```

### Alternativa Rápida (Copy & Paste):

Si quieres una solución inmediata, puedes descargar este archivo gratuito:

**URL directa:**
```
https://freesound.org/data/previews/215/215415_3905781-lq.mp3
```

1. Clic derecho → "Guardar enlace como..."
2. Guardar como: `flip.mp3`
3. Mover a: `public/sounds/flip.mp3`

### Verificar que Funciona:

Una vez agregado el archivo, recarga la página del manual y al cambiar de página deberías escuchar el sonido.

---

**Nota:** El código ya está preparado para usar el sonido. Solo falta que agregues el archivo MP3.
