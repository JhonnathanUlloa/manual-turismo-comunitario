# 📁 Carpeta de Imágenes del Manual

## 📍 Ubicación
Esta carpeta contiene todas las imágenes que aparecen en el manual de usuario del sistema de turismo comunitario.

## 📷 Convención de Nombres

Por favor, nombra las imágenes según la sección:

### Formato:
`seccion-[número]-[descripción].jpg`

### Ejemplos:
- `seccion-1-introduccion.jpg`
- `seccion-2-login.jpg`
- `seccion-3-dashboard.jpg`
- `seccion-4-comunidades.jpg`
- `seccion-5-eventos.jpg`
- `seccion-6-reservas.jpg`
- `seccion-7-usuarios.jpg`
- `seccion-8-roles.jpg`
- `seccion-9-reportes.jpg`
- `seccion-10-configuracion.jpg`

## 📐 Especificaciones Recomendadas

- **Formato:** JPG o PNG
- **Ancho:** 800-1200px
- **Proporción:** 16:9 o 4:3
- **Peso:** Menos de 500KB por imagen
- **Calidad:** 80-90%

## 🔍 Detección Automática

El sistema buscará automáticamente imágenes con este patrón:
- `/images/manual/seccion-1-*.jpg`
- `/images/manual/seccion-2-*.jpg`
- etc.

Si no encuentra una imagen específica, mostrará un placeholder indicando qué imagen debe ir ahí.
