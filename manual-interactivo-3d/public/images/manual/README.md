# 📁 Carpeta de Imágenes del Manual

## 📍 Ubicación
Esta carpeta contiene todas las imágenes que aparecen en el manual de usuario del sistema de turismo comunitario.

## 📷 Convención de Nombres

Por favor, nombra las imágenes según la sección:

### Formato:
`seccion-[número].png`

### Ejemplos:
- `seccion-0.png` - Portada
- `seccion-1.png` - Plataforma
- `seccion-2.png` - Índice
- `seccion-3.png` - Introducción
- `seccion-4.png` - Acceso al Sistema
- `seccion-5.png` - Navegación Básica
- `seccion-6.png` - Gestión de Alojamientos
- `seccion-6,5.png` - Alojamientos (imagen adicional)
- `seccion-7.png` - Experiencias y Rutas
- `seccion-8.png` - Gestión de Platos
- `seccion-9.png` - Gestión de Productos
- `seccion-10.png` - Gestión de Restaurantes
- `seccion-11.png` - Preguntas Frecuentes
- `seccion-12.png` - Soporte Técnico
- `seccion-13.png` - Consejos Finales

## 📐 Especificaciones Recomendadas

- **Formato:** PNG (obligatorio)
- **Ancho:** 1024-1280px
- **Proporción:** 16:9 (horizontal)
- **Peso:** Menos de 2MB por imagen
- **Calidad:** Alta resolución

## 🔍 Detección Automática

El sistema buscará automáticamente imágenes con el patrón:
- `/images/manual/seccion-0.png`
- `/images/manual/seccion-1.png`
- `/images/manual/seccion-2.png`
- etc.

Si no encuentra una imagen específica, mostrará un placeholder indicando qué imagen debe ir ahí.
