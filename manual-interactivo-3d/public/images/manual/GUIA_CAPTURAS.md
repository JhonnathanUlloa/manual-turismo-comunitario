## 🛠️ Herramientas para Capturas

### Windows:
- **Win + Shift + S** → Seleccionar área
- **Snipping Tool** → Captura completa
- **ShareX** (gratis) → Capturas profesionales con edición

### Configuración recomendada:
- ✅ Zoom del navegador: 100%
- ✅ Resolución pantalla: Mínimo 1920x1080
- ✅ Modo: Pantalla completa del navegador
- ✅ Limpiar: Cerrar notificaciones y elementos personales

---

## 📐 Especificaciones Técnicas

| Propiedad | Valor |
|-----------|-------|
| Formato | PNG (preferido) o JPG |
| Dimensiones mínimas | 800x600px |
| Dimensiones ideales | 1200-1400px de ancho |
| Peso máximo | 500KB (comprimir con TinyPNG si es necesario) |
| Fondo | Blanco o transparente |
| DPI | 72-96 (web) |

---

## ✂️ Post-procesamiento (opcional)

1. **Recortar:** Eliminar barras de título del navegador si es posible
2. **Redimensionar:** Mantener proporción 16:9 o 4:3
3. **Comprimir:** Usar https://tinypng.com si el archivo supera 500KB
4. **Limpiar:** Difuminar información sensible si la hay
